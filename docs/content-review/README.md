# janus-site content review

This folder contains a page-by-page review of the live marketing site (`janus-site/`).

- **`content-*.md`** — the on-page text content only (headings, body copy, labels, CTAs), with all HTML/CSS/JS stripped out. One file per page.
- **`accuracy-*.md`** — for each page, a list of claims that were checked against the current `JanusV7` codebase/docs, flagged as **Accurate**, **Needs update**, or **Unverified**, with the evidence found.

Pages reviewed: `index.html` (Home), `product.html`, `technical.html`, `company.html`, `roadmap.html`, `about.html`, `blog.html` (redirect only).

Reference repo used for fact-checking: `/home/jesse/Janus/JanusV7` (backend, docs, tests, AGENTS.md, PRODUCT.md).
