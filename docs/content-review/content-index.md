## Demo block
**Label:** See it work
**Heading:** See a gate stop a workflow — then see a human clear it.

1. **Gate fires** — A scheduling or drift condition is met. The workflow card moves to Blocked — children do not advance.
2. **Operator reviews in chat** — The operator opens the card. Answers are grounded in institutional memory — contracts, gate context, prior decisions.
3. **Human resolves** — Approve, hold, or allow with debt. The decision is logged. The workflow continues to Completed.
